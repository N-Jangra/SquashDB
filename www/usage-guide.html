Usage Guide

How to use each tab and setting.

Dashboard

Your tracked titles, grouped by category (TV Series, Movies, Anime, Manga, Games, etc — whichever you've enabled in Settings → Tracking Choices). Switch between a list view and a poster grid in Settings → Appearance. Tap a card to open its detail page; use the search bar and status filter to narrow a long list.

Discover

Pick a category chip, then search — results merge across every enabled metadata source for that category. Tap the filter (sliders) icon next to the search bar to limit a search to specific sources only; that choice is saved per category. Tapping a result opens its detail page; nothing is saved to your list until you change something there.

Sources & Explore

Sources lists every built-in metadata source, so you can search just one directly. Explore is a shortcut hub: only your currently enabled sources, plus quick links to Timeline and Statistics, and a toolbox icon to Settings → Metadata Sources to enable more.

Show/Movie Detail Page

Shows poster, summary, and metadata at the top. The Tracking group lets you set which list it belongs to, its status, and a completion date. Series/anime/dramas get a season picker and episode list — tapping an episode's checkmark marks it (and everything before it) watched, which also updates status automatically. Rating and Notes sections are always available. A delete option appears in the topbar only while a title is still in Watchlist or In Progress.

Timeline & Statistics

Timeline shows a chronological feed of completions and episode-watch activity. Statistics summarizes genres, networks, ratings, and time spent watching, including a weekly chart and your biggest single-day marathons.

Settings

Every group and page in Settings, in order, with what each one does.

Appearance

  • Theme — switch between dark, light, and other built-in themes.
  • Font — change the font used across the whole app. System fonts (System Default, Inter, Outfit, Serif, Monospace, Rounded) work fully offline; the "(online)" options are downloaded once from Google Fonts on first use, then cached on-device — and mirrored to your backup folder if one is set — so they keep working offline afterward.
  • Main Color — change the app's accent color.
  • Animation Speed — control how fast transitions and animations play throughout the app.
  • Dashboard View — show tracked items as a list or a poster grid.
  • Dashboard Row Actions — choose whether edit/delete on a row use a 3-dot menu or swipe.
  • Rating Format — display ratings as 5 stars, a 10-point score, a 10-point decimal, or 100 points.

App Identity

  • App Icons and Names — change the icon and display name shown on your home screen.
  • Bottom Menu Icons — customize which icon represents each tab in the bottom navigation.
  • Bottom Bar Layout — reorder tabs and choose which ones appear (Settings can never be hidden).

Tracking

  • Tracking Choices — turn tracking categories (TV Series, Movies, Anime, etc.) on or off, or add custom ones.
  • Category Order — drag to reorder your enabled categories as they appear across the app.

Metadata

  • Metadata Mode — Offline keeps everything manual; Online enables looking up metadata and thumbnails.
  • Metadata Thumbnails — turn thumbnail fetching and display on or off.
  • Metadata Sources — enable/disable, reorder, add API keys for, or create custom lookup sources (used by Discover and Sources).

Backup & Sync

  • Folder Sync Delay — how long to wait after a change before syncing to your chosen backup folder.
  • Backups & Restore — export your data as a file, restore from a backup, or sync to a folder as a mirrored file tree.

Security

  • App Password — require a password (with security questions for recovery) to open the app.
